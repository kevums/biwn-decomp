BIWN native CD resource loader: source recovery and component checks

The resource loader at 0x1B044 is now recovered as readable C with an original 68000 ABI wrapper. Its original body is 272 bytes and 72 instructions; the tested standalone replacement is 2,416 bytes. The accepted component source is coordinator-authored. It has not been added to a new game disc, and the playable preview remains unchanged.

What passed

780 native CPU cases compare all data/address registers, PC, SR, both stack pointers, the original 24 saved bytes, public RAM, and helper entry registers, flags, arguments and stack positions. Another 84 cases compare ordered memory accesses in Unicorn. The fixtures execute all 72 original instructions. They cover busy waits, delayed reads, partial markers, retries, boundary conditions, copy sizes, optional completion flags and null handles. Three deliberately introduced defects were caught by execution comparisons: accepting 15 marker words, omitting the completion write, and clearing the lock on the null-handle return.

The controlled provider initially cleared the loader's own lock while waiting for a read. That fixture was corrected, and all 780/84 cases reran with explicit final lock and readiness assertions. The original null-handle path leaves the lock set; this source preserves that behavior. Earlier results and the failed negative-control driver remain archived.

Actual dependency checks

Sixteen two-client cases run original acquire with compiled load. Another sixteen run compiled acquire and load with the existing compiled heap, copy and scheduler helpers. Each profile checks 1,538,816 payload bytes against preserved normalized disc data. Both callers receive the same handle; the reference count reaches two; the loader sets readiness and wakes the waiter. Returned CPU state, public RAM, semantic calls and payloads match the original.

These are declared synthetic startup fixtures. Actual CD math, kernel and other retained helper instructions execute, but two explicit BIOS adapters and external disc completion remain. They do not establish cold-game, interrupt, reentrancy or physical-console behavior.

The nested tests observe a minimum 24-byte gap between loader execution and acquire's private state, and a 28-byte gap between loader helper execution and loader private state. These are margins observed in these fixtures, not worst-case bounds.
